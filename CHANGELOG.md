# Changelog

## [1.0.0] - 2026-11-01

Initial public release of Doggy Avatar Generator, adapted from
[Animatar](https://github.com/luizvbo/animatar) and
[Animal Avatar Generator](https://github.com/roma-lukashik/animal-avatar-generator).

- Standalone, programmatic ESM API with TypeScript declarations and no runtime dependencies.
- 120 stylized breed recipes and 76,800 fixed collection entries.
- Configurable expressions, coat palettes, clothing, headwear, accessories, and independent styling colors.
- Automatic large-head composition at 24/32px and normal half-body composition at other sizes.
- Deterministic seeds, separate anatomy and styling streams, and lazy per-breed collection sampling.
- Installable package archive, standalone ESM module, declaration file, and SHA-256 checksums.
- English documentation and retained upstream copyright and license notices.
